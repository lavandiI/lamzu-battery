# Проверка Rust-сборки на живой системе

Дата: 20.11.2026. Windows 11, LAMZU Thorn через донгл `3554:F50D`, сборка
`dist\LamzuBattery.exe` 1.6.0 (release, `panic = "abort"`).

| Проверка | Как проверялось | Результат |
| --- | --- | --- |
| HID-диагностика | `--diagnose --lang en` | `3554:F50D`, usage page `0xFF02`, **88 %** (raw 85 %, 4055 мВ), код возврата 0 |
| Сырые отчёты | `--diagnose --raw` | `08 04 00 00 00 02 55 00 0f d7 00 00 00 00 00 00 0c` |
| Иконка и тултип | UI Automation области уведомлений | `SystemTray.NormalButton`, тултип `LAMZU Battery: 87% (discharging)` |
| Авто-закрепление на панели задач | журнал | первый запуск — `tray promotion (auto): Promoted`, далее `Already` |
| Меню | открыто через UI Automation | все пункты и состояния на месте: имя, статус, Refresh, Start with Windows, Open data folder, Show icon on taskbar, Open release page, Install updates automatically ✓, Check for updates, Language ▸, Exit |
| Refresh battery manually | пункт меню | `polled_unix` в `status.json` сдвинулся на момент действия |
| Check for updates | пункт меню | `update_last_check_unix` обновился; живой запрос к GitHub API успешен, новых версий нет (1.5.11 < 1.6.0) |
| Language → Русский | пункт меню | `settings.json` и `status.json` содержат `language: "ru"`, журнал `language = ru` |

| Exit | пункт меню | процесс завершился, `status.json` содержит `running: false`, журнал `tray stopped` |
| Второй экземпляр | запуск поверх работающего | выход за 20 мс (см. `benchmark.md`) |
| `--wait-for-instance` | запуск, затем убийство первого процесса | новый процесс дождался мьютекса, стал владельцем `status.json` и поднял трей |
| Тост | `cargo test --test live -- --ignored` | WinRT принял уведомление, AppUserModelId зарегистрирован |
| Автозапуск (модуль) | тот же live-тест | включение, проверка, выключение и восстановление прежнего значения Run-ключа |
| Краш-лог | `tests/crash_report.rs` | паника попадает в `crash.log` вместе с потоком, местом и сообщением; старый большой лог обрезается при старте |
| Обновление с GitHub (живой API) | `tests/live.rs` | запрос и разбор ответа работают, отказ («новее нет») корректен |

## Не проверено вживую

- **Полная установка обновления с GitHub.** Более новой версии, чем 1.6.0, нет;
  путь «preflight → скачивание → SHA-256 → `MZ` → замена → health-check →
  откат» покрыт интеграционными тестами с локальным HTTP-сервером
  (`tests/http.rs`, `tests/updater.rs`).
- **Уведомления «низкий заряд» и «мышь заряжена».** Требуют реального разряда
  или полной зарядки батареи; используется тот же WinRT-путь, который проверен
  live-тестом тоста.
- **Пункт «Show icon on taskbar» из меню.** Автоматическое закрепление
  отработало вживую, решения `promote`/`promote_if_unconfigured` покрыты
  тестами с фейковым реестром, но ручной пункт в этом прогоне активировать не
  удалось: фокус уходил из меню при программном вводе.
- **Качество цифр на самой панели задач** глазами проверить нельзя; рендер
  проверен тестами и картинкой [`preview.png`](preview.png).

## Побочные эффекты прогона

- Пункт «Open release page» был случайно активирован при отладке навигации по
  меню: в браузере открылась страница релиза. Пункт работает, вкладку можно
  закрыть.
- Во время проверок Rust-сборка один раз переписала Run-ключ на свой путь
  (проверка автозапуска); исходное значение `...\Lamzu\dist\LamzuBattery.exe`
  восстановлено, Python-приложение снова запущено.
